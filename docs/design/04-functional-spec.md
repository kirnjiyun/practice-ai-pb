# W3 기능 명세 — 투자성향 진단·자산 관리

## 투자성향 진단

상담 전에 사용자의 생각을 정리하기 위한 **데모 전용 분류**다. 실제 금융기관의
적합성·적정성 평가를 대체하거나 상품 추천/가입을 허용하는 판정에 사용하지 않는다.

- 문항 버전 `demo-v1`: 기간, 경험, 하락 대응, 우선순위, 여유자금의 고정 순서 5문항.
- 각 응답은 1~5의 정수이며 모든 문항을 답해야 한다. 소수·null·범위 밖 값은 400.
- 점수는 서버가 합산한다. 클라이언트의 score/riskLevel/userId는 사용하지 않는다.
- 5~8 안정형, 9~12 안정추구형, 13~16 위험중립형, 17~20 적극투자형, 21~25 공격투자형.
- 경계값과 질문 내용은 실증된 금융 모델이 아닌 프로젝트 가정이다.
- 결과는 추가 저장하며 이전 결과를 덮어쓰지 않는다. 조회는 최신 결과 1건.
- 유효기간은 진단 시점부터 정확히 365일. 만료 결과도 반환하되 expired=true로 재진단을 안내한다.
- 결과가 없으면 204. 요청 문항 버전이 다르면 409로 새 설문을 요청한다.

## 자산 관리

현금·입출금, 예·적금, 주식, 펀드, 채권, 연금, 기타, 부채를 등록한다.
이름은 공백 제외 내용이 있어야 하며 최대 80자다. 실계좌 번호나 실제 개인 정보는 입력하지 않는다.

- 원화 금액만 지원. 1~999,999,999,999원의 정수로 저장한다.
- 부채도 양수로 입력하며 총자산에서는 제외한다. 순자산 = 총자산 - 총부채로 음수가 가능하다.
- 소유자는 JWT subject로 결정한다. 모든 목록/상세/수정/삭제 조회에 user_id 조건을 넣는다.
- 다른 사용자 자산과 존재하지 않는 자산은 동일하게 404. PB/ADMIN도 이 API에서는 본인 자산만 접근한다.
- 수정은 version을 필수로 전달한다. 삭제도 query의 version을 요구한다.
  오래된 version이나 동시 수정은 409로 거절하며 새로고침 후 재시도하게 한다.
- 웹 삭제는 항목별 확인 UI를 거친다. 수정 실패 시 입력은 유지한다.
- 자산 목록은 이름·ID 오름차순. 현재 소규모 데모용 전체 목록이며 페이지네이션은 후속 과제다.

user3는 빈 상태를 유지한다. 기존 계정의 사용자 입력 데이터는 수정하지 않는다.
