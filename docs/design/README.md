## 문서 작성 규칙

- 각 기능은 **왜 필요한가 / 어떻게 구현하는가 / 실패 시 어떻게 처리하는가** 세 축으로 씁니다.
- 다이어그램은 Mermaid로 작성하고, 렌더 이미지가 필요하면 `docs/diagrams/`에 함께 둡니다.
- 금융 규제 판단이 필요한 부분은 단정하지 않고 **`⚖️ 법무·컴플라이언스 검토 필요`**로 표기합니다.
- 수치는 측정 전까지 목표치로만 적고, "측정치"로 기재하지 않습니다.
